# Troubleshooting

- **Old shortcut kept the previous path.** Start `setup` in the folder at its new place.
- **Files may disappear when extracting.** Make sure to back up any files you've added before extracting a new archive over the existing folder.
- **Path Length Issue.** Windows may report that the path is too long. To resolve this, extract the files closer to the drive root.
- **High-DPI scaling makes text tiny.** Right-click `setup`, open Properties, Compatibility, Change high DPI settings, and set Override to System.
